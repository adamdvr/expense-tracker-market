## Summary
- настроен Jest для backend: `jest` + `ts-jest` + `@nestjs/testing` (10.x, совместим с Nest 10), скрипт `npm run test`, спеки исключены из `nest build` через `tsconfig.build.json`, алиас `@/*` доступен в тестах
- написан `transactions.service.spec.ts` (19 кейсов): доступ только к своим транзакциям/категориям (`NotFoundException` без обращения к репозиторию для update/delete), `findAll` отдаёт переданные `page`/`limit`, `getSummary` — границы месяца в UTC, суммы в `Prisma.Decimal` без ошибок округления, сортировка категорий по убыванию суммы
- документация (`developer-guide.md`, `architecture.md`, `apps/backend/CLAUDE.md`) больше не утверждает, что автотестов нет: описаны команда запуска и текущее покрытие

## Почему
В проекте не было тестовой инфраструктуры — ни скрипта `test`, ни конфига Jest, ни одного `*.spec.ts`. `TransactionsService` — самое насыщенное правилами место backend (user-scoped доступ, денежные суммы в `Decimal`, границы дат в UTC), поэтому Jest настроен вместе с первым реальным тестом на нём, а не отдельно вхолостую.
